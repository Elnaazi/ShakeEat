Project Overview: ShakeEat is an Android application designed to simplify meal selection by recommending dishes based on the user’s current mood. Built with Kotlin and Jetpack Compose, the app delivers a modern, responsive user experience centered around quick decision making and personalized food suggestions.


The app guides users through a streamlined flow:

• Select one or more moods


• Shake the device to generate a food suggestion


• Review the recommended dish


• Explore the recipe or choose a different mood



Key Features:


• Mood based recommendation engine


• Intuitive interface


• Clean UI built with Jetpack Compose


• Navigation driven user experience


• Local persistence for dish and app state management


• Scalable architecture for future expansion


Technologies:


• Kotlin

• Android Jetpack


• Jetpack Compose


• Room Database


• Navigation Component
